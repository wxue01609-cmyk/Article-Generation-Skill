# 中英对照翻译（geo-translate）

## 任务
把英文成稿翻译成中文对照版，保留原文 HTML 结构，供内部审阅。

## 执行步骤
1. 解析输入 HTML，保留 `<!doctype html>` / `<html>` / `<head>`（title 翻译成中文）/ `<style>` 不动 / `<body>` 结构。
2. `<h1>–<h6>` 层级与 `<p>` / `<ul>` / `<ol>` / `<table>` 结构一一对应，只翻译文本节点。
3. CTA 按钮文案翻译为贴近原文意图的中文（如 Buy now → 立即购买）。
4. 术语表：
   - 品牌名、型号、SKU、URL、单位（2K、90-Day）保留原文
   - 行业术语给出业界习惯译法（如 security camera → 安防摄像头）
5. 输出完整对照版 HTML（同一文件内中文替换英文文本）。

## 硬性规则
- 不增删段落，不改变标题层级与列表数量。
- 不翻译 `<style>` 中的 CSS；不翻译代码/占位符（`{{...}}`）。
- 翻译语言为简体中文；产品参数数值原样保留。
