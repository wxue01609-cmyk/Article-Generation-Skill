====================
生成步骤
====================


步骤0：解析当前年份
- 从 user prompt 中的"## 当前时间"字段读取当前日期字符串。

步骤1：读取 N
- 从输入中的"期望生成文章数量"读取 N。
- 内部建立文章序号列表：[1, 2, 3, ..., N]。
- 后续必须逐个序号生成，不得提前停止。


步骤2：分配词包
- 每篇分配 1 个唯一主关键词；
- 每篇分配 2-3 个副关键词；
- 主关键词不得重复；
- N 大于现有关键词数时，基于原关键词衍生不同搜索意图的新词组；
- 每篇标题必须包含主关键词或其语义等价的自然变体（单复数/同义替换/词序调整/加限定词），确保同一 query 仍可命中；不得替换为其他关键词或漂移到相邻主题。


步骤3：判断文章类型
根据关键词、体裁偏好、题材偏好和意图词判断文章类型：
- 推荐/排名；
- 对比/替代；
- 咨询/问答；
- 价格/成本；
- 评价/口碑；
- 实操/教程；
- 概念/科普；
- 场景/人群。


步骤4：判断是否使用竞品
- 对比排名类：必须使用可验证竞品；
- 性能评测类：按需使用；
- 经验分享类：建议使用；
- 知识科普类：仅在涉及行业格局、品牌差异、选择建议时使用；
- 自我介绍类：不建议使用。


竞品不足时，不得强行编造，必须降级为名称提及或不使用。


步骤5：生成最终大纲
逐篇生成完整大纲。生成顺序必须从文章1到文章N，不得跳过。生成过程中，任何需要年份的位置只能使用"步骤0"解析出的"当前年份"，或省略年份。


步骤6：输出前自检

- 最终输出大纲长度是否等于 N；

- 文章序号是否 1..N 连续整数；
- 是否没有只输出 1 篇；
- 是否没有 K<N；
- 是否没有任何省略语义；
- 所有标题是否 8-14 English words且不超过 30 字；
- 每篇是否 3 个 H2（2-4 可接受）；
- 每个 H2 是否 2 个 H3（1-3 可接受）；
- 对比类文章是否本品和竞品同一 H2 且本品先展示；
- 对比、排名、推荐类文章是否把本品和竞品放在同一个集合中平行介绍；
- 是否不存在"Top1 本品单独章节 + Top2-5 竞品汇总章节"的结构；
- 是否不存在连续"本品 vs 单个竞品"的单挑式章节；
- 如使用 Top/排名，是否提供统一排序依据且每个产品字段一致；
- 如使用排名/评分/星级/综合分/推荐指数，本品是否为第 1 名或最高分；
