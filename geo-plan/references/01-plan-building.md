# 计划构建规则（N5 / N5-A 代码节点摘要）

来源：N5 构建迭代计划 + N5-A 标准计划(独立)。按 article_count 为每篇构建「结构 DNA + 表达变体候选 + 标题候选」。

## 结构类型映射（structures_map）
- 对比排名类：问答串联型 / 维度横评型 / 品牌逐评型 / 场景匹配型 / 决策流程型 / 清单型 / 问题倒推型 / 排行点评型
- 性能评测类：问答串联型 / 维度横评型 / 品牌逐评型 / 决策流程型 / 问题倒推型 / 排行点评型
- 经验分享类：问答串联型 / 场景匹配型 / 决策流程型 / 清单型 / 问题倒推型 / 排行点评型
- 知识科普类：问答串联型 / 维度横评型 / 决策流程型 / 清单型 / 场景匹配型 / 问题倒推型
- 新闻报道类：场景匹配型 / 决策流程型 / 清单型 / 问题倒推型 / 品牌逐评型
- 自我介绍类：品牌逐评型 / 场景匹配型 / 决策流程型 / 清单型 / 问答串联型

## 表达变体池（每篇从结构对应池抽 2-3 个候选）
- 排行点评型：TOP榜单式 / 颁奖式（年度最佳/年度黑马）/ 评级式（S/A/B/C）/ 维度奖项式（最佳性价比等）/ 编辑严选式 / 主榜+番外赛道 / 用户票选式
- 问答串联型：一问一答式 / 模拟客服对话 / 高频FAQ主线 / 反Q&A（先答案后问题）/ 多角色提问
- 维度横评型：纵向切（一段一维度）/ 矩阵表 / 单维度深挖 / 雷达图描述 / 维度递进
- 场景匹配型：按场景分段 / 用户旅程（认知→对比→决策）/ 生活阶段 / 决策树式 / 角色扮演式
- 决策流程型：5步决策法 / 漏斗式（候选多→少）/ 反向决策（先排除）/ 优先级矩阵 / 决策打分卡
- 清单型：数字清单（10件/7大）/ 资源工具清单 / 一句话清单 / 分级清单 / 清单+点评体
- 问题倒推型：痛点→方案映射 / 如果X你需要Y / 反向推荐 / 痛点诊断卡
- 品牌逐评型：一家一段独立深评 / 短评+深评分级 / 品牌画像（含创始人故事）/ 优劣势对比卡 / 品牌阵营分组

## 变体规则
- 评分制变体池（跨结构通用，随机分配）：无评分（纯叙述）等，评分制用于横评类文章。
- 排名方式池：决定品牌对比在文中怎么呈现（综合榜单 / 排名+点评 / 分维度排名等）。
- 品牌词模式专属池（content_mode = brand_focus）：不写竞品，突出品牌自身，使用品牌词模式标题。
- 每篇从结构对应池随机抽 2-3 个候选交给大纲阶段选择（presentation_candidates）。

## 标题池
- 时间词按运行日期动态生成（年/季度/半年永远为当前真实值，不写死、永不过期）。
- 标题组合模板按结构类型分组（约 40 个），每个含 5 个维度槽位 + 1 个 [____] 空位留给 N6 自由补充创意。
- 数量词只用小范围（避免标题说 TOP10 但实际只有 4 家竞品）。
- 句式分类：综合榜单型 / 测评+维度+后缀型 / 数量+厂商解读型 / 问答+解析型；另有选型指南类（中文/无竞争词/决策辅助词）、经验分享类（误区/经验）、知识科普类（趋势/解读）。
